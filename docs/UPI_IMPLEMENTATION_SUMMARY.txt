================================================================================
                          IMPLEMENTATION APPROACH
================================================================================

ARCHITECTURE OVERVIEW:
Frontend (React)
    ↓ (User click)
Client Component: UPIIntentCheckout
    ↓ (Calls server action)
Server Action: createUPIIntentPayment
    ↓ (Validates + calls Razorpay)
Razorpay: Creates order
    ↓ (Returns order_id)
Frontend: Opens Razorpay checkout
    ↓ (Redirects to UPI app)
Customer: Completes payment in UPI app
    ↓ (Webhook event sent)
Backend: Receives payment.authorized webhook
    ↓ (Verifies signature + idempotency)
Backend: Updates database
    ↓ (Transitions job state)
Backend: Creates invoice
    ↓ (Sends confirmation)
Frontend: Shows success page

KEY COMPONENTS:
1. Server Action (backend)
   - Validates job ownership
   - Verifies amount matches quote
   - Creates Razorpay order
   - Stores payment record

2. Client Component (frontend)
   - Loads Razorpay checkout
   - Sets UPI method
   - Handles payment completion

3. Webhook Handler (backend)
   - Verifies Razorpay signature
   - Checks idempotency
   - Updates payment status
   - Transitions job state
   - Creates invoice

4. Database
   - Stores UPI payment metadata
   - Stores QR code data
   - Audit logging
   - RLS policies
